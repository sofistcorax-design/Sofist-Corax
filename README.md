# Sofist-Corax
Sofist Corax – Florida Lottery Statistics  Plataforma avanzada de análisis estadístico de la Lotería de Florida en tiempo real. Incluye análisis de frecuencias, patrones, rachas, estabilidad, intervalos, decenas, terminales y tendencias históricas. Integra Firebase para autenticación, base de datos y servicios en la nube, con una interfaz moderna.
